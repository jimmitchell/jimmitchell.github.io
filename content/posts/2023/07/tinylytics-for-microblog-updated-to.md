<p>Fresh on the heels of new <a href="https://tinylytics.app">Tinylytics.app</a> updates, my <a href="https://micro.blog/account/plugins/view/101">Tinylytics for Micro.blog</a> plug-in has been updated to take advantage of the new Kudos feature introduced in the latest release. If you look at your installed site plug-ins, you should see an update available as 1.0.6.</p><!--more-->

This release adds a checkbox to show Kudos along with the ability to set a custom label. See the project <a href="https://github.com/jimmitchell/Tinylytics-for-Micro.blog/blob/main/README.md">README</a> on Github for more information.
