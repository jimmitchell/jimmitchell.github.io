![TinylyticsHeaderArt](/media/2023/tinylyticsheaderart.png)

<p>Hot on the heels of <a href="https://vincentritter.com/2023/07/10/19-47-43">uptime monitoring on Tinylytics</a>, I’m stoked to share that my <a href="https://micro.blog/account/plugins/view/101">Tinylytics for Micro.blog</a> plug-in has been released as a 2.1 version to take advantage of it.</p><!--more-->

This release adds the following:

<ol>
<li>The ability to use a <a href="https://gohugo.io/content-management/shortcodes/">Hugo shortcode</a> to add a <span style='text-decoration:underline;'>Page View Counter</span> in a post without changing any site template files. This will display the actual views of a single post, rather than overall hits -- which can still be shown as a footer embed.</li>
<li>The ability to show your site uptime embedded in the global custom footer of your Micro.blog site without changing any site template files.</li>
</ol>

<i><b>Note:</b> Uptime monitoring is a paid feature of Tinylytics. You'll need to have a paid account for uptime stats to show via this plugin.</i>

You should see a new version available in your site plug-ins area soon.

For more details about using the plug-in, see the <a href="https://github.com/jimmitchell/Tinylytics-for-Micro.blog/blob/main/README.md">README</a> on the <a href="https://github.com/jimmitchell/Tinylytics-for-Micro.blog">Github project</a> page.

If you have any other questions or find a bug, contact me through any of the methods in my site footer below.
