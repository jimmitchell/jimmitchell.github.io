<p>I’m happy to share that my <a href="https://micro.blog/account/plugins/view/101">Tinylytics for Micro.blog</a> plug-in has been released as a 2.0 version.</p><!--more-->

This release adds the following:

<ol>
<li>A complete refactor/rewrite of the tracking code for better performance.</li>
<li>The ability to use <a href="https://gohugo.io/content-management/shortcodes/">Hugo shortcodes</a> to add Kudos and Hit Counter in a post without changing any site template files.</li>
<li>The ability to add a Hit Counter embed in the global custom footer of your Micro.blog site without changing any site template files.</li>
</ol>

You should see a new version available in your site plug-ins area soon.

For more details about using the plug-in, see the <a href="https://github.com/jimmitchell/Tinylytics-for-Micro.blog/blob/main/README.md">README</a> on the <a href="https://github.com/jimmitchell/Tinylytics-for-Micro.blog">Github project</a> page.

If you have any other questions or find a bug, contact me through any of the methods in my site footer below.
