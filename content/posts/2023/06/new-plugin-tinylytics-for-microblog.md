<p>I published my very first Micro.blog plugin today: <strong>Tinylytics for Micro.blog</strong>. You can find it in the Micro.blog <a href="https://micro.blog/account/plugins/view/101">plugin directory</a>.</p><!--more-->

If you’re using <a href="https://micro.blog/vincent">Vincent Ritter’s</a> awesome web analytics platform <a href="https://tinylytics.app">Tinylytics</a>, this plugin is for you. Rather than copying and pasting a line of Javascript, you simply enter your unique site id which can be copied from your site page once the plugin is installed.

<img src="/media/2023/tinylytics-plug-in-options.png" alt="Tinylytics plug in options" title="tinylytics-plug-in-options.png" border="0" width="562" height="179" style="border:1px solid var(--code);" />

There’s an option to toggle the “Display Hits” option too.

To show hits on your site, you’ll need to modify your Micro.blog theme to make the hits show up. The easiest way to accomplish this might be to add code in the footer of your theme’s design area (Design > Edit Footer):

<img src="/media/2023/footer-edit.png" alt="Footer edit" title="footer-edit.png" border="0" width="718" height="185" style="border:1px solid var(--code);" />

See this Tinylytics <a href="https://tinylytics.app/docs/show_hit_counter">help article</a> for more information on displaying hits on your site.

The plugin source can be found at this Github repo: <a href="https://github.com/jimmitchell/Tinylytics-for-Micro.blog">https://github.com/jimmitchell/Tinylytics-for-Micro.blog</a>.
