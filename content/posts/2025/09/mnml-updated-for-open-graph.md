date: "2025-09-19T15:56:16-07:00"

I'm happy to report that **mnml** is updated (v2.7.5) to work with [@manton](https://micro.blog/manton)'s latest [Open Graph image](https://www.manton.org/2025/09/18/updated-the-new-help-page.html) Micro.blog enhancement.

From your Design screen, select the "**mnml**" Open Graph style option and start publishing! It will even use your **mnml** custom avatar if you have one set.

Give it a spin! Report any issues you run into if you do.
