title: "Another mnml Release"
date: "2025-05-24T22:11:12-07:00"
---
A new release of **mnml** has been published that adds the following features:

* Added Microformats to make **mnml** compatible with the [new "use blog theme" preview feature](https://news.micro.blog/2025/05/24/another-new-update-to-microblog.html) added to the [Micro.blog for macOS](https://help.micro.blog/t/micro-blog-for-mac/45) application. Props to [@manton](https://micro.blog/manton) for sharing a pull request to get me headed in the right direction.
* For those who would like to use icons in their navigation menus, or page and post titles, this release adds the ability to use Fontawesome or Phosphor Icons. A post will be coming over on [mnml.micro.blog](https://mnml.micro.blog) with more details about this feature soon.

You should see an update available in your plugin listing soon if you don't already. As always, thanks to all who continue to support **mnml** development.
